## Notes for General Assembly - Modern Engineering Sandbox

THE FOLLOWING ACTIONS ARE PERMITTED FOR SANDBOX USERS

### DynamoDB

Allowed 1 - Table

1. Allow Create, Update, and Delete DynamoDB Table and Items
2. Allowed Region: N.Virginia (us-east-1)

### RDS

Allowed 1 - RDS Running

1. Allow create, update, and delete RDS Instances &amp; Snapshots.
2. Database Engine: MySQL
3. Instance Size: db.t3.micro.
4. Storage: 20 GB.
5. Allowed Regions: N.Virginia (us-east-1)

### EC2

Allowed 1 - EC2 Running

1. Allow launch and terminate Instances.
2. Instance Type: t2.micro &amp; t3.micro
3. Volume: 30 GB, General Purpose SSD (gp2), General Purpose
   SSD (gp3).

### API Gateway

1. Allow Build, Deploy, and Delete REST API
2. Allow Build, Deploy, and Delete HTTP & Web Socket API
3. Read Access to Amazon API Gateway Service
4. Allowed Region: N.Virginia (us-east-1)

### CloudFormation

1. Allow Create, Update and Delete CloudFormation Stacks
2. Allow Create and Delete CloudFormation Change Set
3. Allowed Region: N.Virginia (us-east-1)
