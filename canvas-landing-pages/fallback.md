## About

This module introduces students to key tools for automating infrastructure management: Ansible and Terraform. Students will learn foundational concepts of Infrastructure as Code (IaC), understand the benefits of automating deployments, and gain hands-on experience with real-world tasks such as setting up environments, automating software installations, and deploying infrastructure on AWS.
